# VoxForge Gaming — Precision PC Components & Rig Configurator

A master-crafted, dependency-free static storefront mock built to demonstrate enterprise standards in accessible web craft, reactive state management, and domain-specific rule validation.

## Architecture & Constraints

- **Direct File-Protocol Operability:** Runs natively via double-click on `index.html` with zero build tools, node dependencies, or local web server requirements.
- **Resilient Persistence:** Features a custom storage adapter that automatically leverages `localStorage` when permitted, with seamless in-memory fallbacks when local privacy environments restrict `file://` writes.
- **Architectural Sockets & TDP Validation Engine:** Interactive PC rig builder with real-time socket alignment verification (e.g., AM5 vs. LGA1700), wattage calculation, and recommended power supply headroom.
- **Reactive Cart & Shelf Recommendations:** Context-aware add/remove/update cart engine with dynamic complementary product triggers.
- **WCAG 2.2 AA Conformance:** Full `:focus-visible` keyboard operability, pauseable ticker strips, and `@media (prefers-reduced-motion)` compliance.
