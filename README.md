# VoxForge Mock Shopify Storefront

Minimal mock storefront built as a static demo.

To run: open `index.html` in your browser (no server required).

Files added:
- `index.html` — main page
- `styles.scss` — SCSS source
- `styles.css` — compiled CSS used by the page
- `script.js` — UI logic: carousel, cart, recommendations

Notes:
- Images use Unsplash random queries as placeholders.
- The recommendation engine is lightweight and rule-based for demo purposes.
